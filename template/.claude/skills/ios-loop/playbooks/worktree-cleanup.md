# Worktree and simulator cleanup

**You own the disk and the safety gate.** Remove merged or abandoned worktrees, the simulators and DerivedData they hold, and stale simulator state, to reclaim space. Deletion is irreversible, so every step guards against deleting something in use or holding uncommitted work. Each kit worktree carries its own simulator and `.build/dd`, often several GB together.

1. **Snapshot and audit.** Record `df -h /`. List every worktree from `git worktree list --porcelain`, never from hand-typed paths, since a worktree made by `claude --worktree` lives somewhere other than one made by `scripts/ai/worktree.sh` (principle-encode-lessons-in-structure). For each one, record its size (`du -sh`), the age of its last commit, its PR state (`gh pr view <branch> --json state`), uncommitted work (`git -C <path> status --porcelain`), unpushed commits (`git -C <path> rev-list --count @{u}..HEAD`), its simulator (`SIM_UDID` in `<path>/.claude/ios.local.env`), and the newest transcript that touched it (the modification time of `~/.claude/projects/<its path with every non-alphanumeric as ->/`). Hand the audit to a subagent (`model: haiku`) when there are many worktrees, and keep only the table. **Check.** The table has one row per `git worktree list` entry, each with a suggested bucket (safe, wip, in-use, keep).
2. **Let the lever take the easy ones.** `scripts/ai/worktree.sh prune` removes PR worktrees (`<repo>-pr<N>`) whose PR is merged or closed, with their simulators, and keeps and names any with uncommitted or unpushed work (principle-build-the-lever). **Check.** Its output names every worktree it removed and every one it kept, with the reason.
3. **Treat the bucket as advice, not permission.** The sessions the owner has open are the real artifact (principle-prove-it-works). Ask the owner which sessions and worktrees are active, and cross-check every candidate against that set. A worktree with a transcript from the last day, or a running process with its path as working directory (`lsof +D <path>` is slow, so check `ps` first), is in use until shown otherwise. For each doubtful row, have a subagent read that worktree's latest transcript and report whether the session is still going and which other worktrees it spawned (principle-guard-the-context-window). Arena and prototype runs leave sibling worktrees whose names never appear in the main session. **Check.** Every candidate is marked in-use or not, with the evidence.
4. **Pause on irreversible loss.** `wip:N` means N tracked files with uncommitted changes. Show the diff and get the owner's decision first. A clean worktree is recoverable from its branch, uncommitted work is not. `scratch:N` means untracked throwaway, safe to drop, but name the files. Unpushed commits are wip too. Clean, merged and not in use proceeds. wip and in-use pause. **Check.** Every wip or in-use row has the owner's decision or stays.
5. **Remove the confirmed set.** `scripts/ai/worktree.sh remove <path>` per path. It lets git refuse a worktree with modified or untracked files first, and only then deletes that worktree's simulator. When git refuses a worktree step 4 already cleared, `git worktree remove --force <path>`, then delete its simulator by UDID (`xcrun simctl delete <udid>`), then `git worktree prune`. Branch refs survive, so no commit is lost. **Check.** `df -h /` and `git worktree list` again.
6. **Reclaim simulator space, then other caches.** Ask before deleting a simulator you did not create (Autonomy, in the `ios-loop` skill).
   - Orphaned kit simulators. Every kit simulator is named `ai-<checkout name>-<hash>`. One whose UDID no live worktree's `.claude/ios.local.env` names is an orphan. Delete it by UDID with `xcrun simctl delete <udid>`, never by name and never `booted`.
   - Test clones. `xcrun simctl --set testing delete all` removes the XCTest clone devices.
   - Unavailable devices. `xcrun simctl delete unavailable`.
   - Old runtimes. `xcrun simctl runtime list`, then `xcrun simctl runtime delete <id>` for runtimes no project targets.
   - More when needed. Each removed worktree's `.build/dd` is gone with it. Xcode's `~/Library/Developer/Xcode/DerivedData`, `~/Library/Developer/Xcode/iOS DeviceSupport` for OS versions no device runs any more, and package caches (SwiftPM, Homebrew). Clear only caches the owner has not said to keep.

   **Check.** `df -h /` shows the space reclaimed, and `xcrun simctl list devices` still shows every live worktree's simulator.

This is the one playbook that deletes state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h /` before and after with the space reclaimed, the worktrees and simulators removed, and a one-line reason for each one held back (in use by which session, or uncommitted work).
